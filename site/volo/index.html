The itch

I've been playing a lot of flag football through Volo, and drop-ins (single pickup games you can jump into) fill up fast. There was no way to get notified when a new one opened, so I kept finding out too late. I want to play as much as possible, so I built the alert.

Yes, it's password protected. The whole advantage of getting the alert is that everyone else doesn't. 😈

What it does

  • Once an hour it checks Volo for new drop-ins in New York, across 11 sports.
  • Every new game goes out by email to the people who picked that sport, exactly once.
  • Signing up takes an email and the sports you care about. AWS sends a confirmation link first, and every alert has an unsubscribe link.

How it works

A scheduled function asks Volo for the current drop-ins, skips the ones it has already announced, and publishes the rest. Email delivery and per-sport filtering are handled by AWS SNS, so there's no mailing list for me to manage.

The password is checked by the sign-up function, not the page, so it can't be skipped by poking at the website. It's the same code as the original invite links, which still work.

Each game only goes out once. The poller remembers every drop-in it has announced, until a day after the game, so a game that gets re-listed doesn't trigger a second email.

What's next

Counting. Every new drop-in will be tallied per day, and the Live page will chart how many show up and how many are flag football.
